# Saving and exporting data

To export original data files You can export the original data files using File > Export data

This will <b>not</b> include any changes you made to the annotations. This will export the original files as you loaded them.

## To save changes you made

You can save any changes you made, along with the unchanged annotations using File > Save Annotation.

This will pop-out a new dialog that lets you pick a file name and what exactly you want to save.
