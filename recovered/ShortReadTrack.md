# Short Read Track

The short read alignment track consists of two parts. The top is a coverage plot on a log2 scale for the read coverage. The second part only show when you are sufficiently zoomed in and shows the individual reads.\r\n\r\nThe color key for the default color scheme.


 \r\n\r\n<table>\r\n<tr><td><strong>Color</strong></td><td><strong>Description</strong></td></tr>\r\n<tr><td>Green</td><td>Read mapped to the forward strand</td></tr>\r\n<tr><td>Blue</td><td>Read mapped to the reverse strand</td></tr>\r\n<tr><td>Yellow</td><td>Mismatch between the read and the reference, the read nucleotide will be shown when zoomed in</td></tr>\r\n<tr><td>Red</td><td>Gap/deletion in the read</td></tr>\r\n<tr><td>Black</td><td>Insertion in the read. Hover over them to see inserted bases.</td></tr>\r\n<tr><td>Gray</td><td>Insertion in the read that is a multiple of 3. Hover over them to see inserted bases.</td></tr>\r\n</table>
