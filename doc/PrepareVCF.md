# Preparing VCF data

[VCF](https://en.wikipedia.org/wiki/Variant_Call_Format) (Variant Call Format) is a text file format that contains meta-information lines, a header line, and then data lines each each containing information about genetic variation at a position in the genome.

[Formal specification](http://www.1000genomes.org/wiki/Analysis/Variant%20Call%20Format/vcf-variant-call-format-version-41/)


## Data preparation

VCF files don't need to be indexed, but it is recommended to reduce their size with [reducevcf](https://github.com/Wouter1/genometools)
